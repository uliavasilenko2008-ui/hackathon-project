# Отчёт: BomzhAI (Support Copilot):

## Метрики на валидации (1000 обращений)
- Язык: 85.7% (сверка с полем lang из выгрузки)
- Пункт правил: 86.2% (125 из 145, только среди обращений, где пункт указан)
- Доля «нужен человек»: 78.5%
- Время на обращение: 5.3 мс (CPU, без GPU)
- Стоимость на обращение: 0 (внешние платные API не используются)

## Примеры черновиков (придуманные обращения):
1. «Игрок оскорбил меня и мою маму в чате» → категория complaint.insult, приоритет p2.
   Ответ: «Здравствуйте! Спасибо за обращение. Мы изучим ситуацию (п. 30:2.1).»
2. «Меня взломали, пропал аккаунт» → категория report.account, приоритет p0, нужен человек.
   Ответ: «Здравствуйте! Ваше обращение передано специалисту поддержки.»
3. «Оплатил донат, не пришло» → категория report.payment, приоритет p0, нужен человек.
   Ответ: тот же, без обещаний возврата.

## Как принимается решение:
Платежи, баны, взлом и жалобы на админов всегда идут человеку. Если пункт
правил не найден или модель в нём не уверена, пункт не цитируется,
и обращение тоже уходит человеку.

## Ограничения:
- Категория и приоритет определяются по taxonomy.json и ключевым словам,
  на валидации не измерены (разметки нет).
- Модель знает не все пункты правил, остальные уходят человеку.
- Дубли и спам определяются упрощённо.
- Узбекский определяется через турецкую модель lingua (прямой поддержки нет).
- Шаблоны на казахском и узбекском созданы с помощью ИИ и требуют проверки носителем.
