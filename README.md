# hackathon-project: 'BomzhAI': триаж обращений игроков. 

# Описание: 
Локальный сервис: определяет языки и тему обращения, находит нарушенный пункт правил, пишет черновик ответа с цитатой пункта и говорит, когда нужен человек(админ). Внешние платные API не используются.

## Установка и запуск:
1.pip install -r requirements.txt

2.Положите файлы выдачи (tickets_train.jsonl.gz, tickets_valid.jsonl, rules.json, taxonomy.json) в папку data/. В репозитории их нет.

3.Сервис: uvicorn main:app, затем POST /triage

4.Пакетный режим: make predict IN=tickets.jsonl OUT=pred.jsonl

5.Страница для ручной проверки: streamlit run app.py

При первом запуске модель поиска пунктов обучается (1-2 минуты) и сохраняется в data/.

## Как устроено:
Нормализация текста, язык (alphabet + lingua), тема по ключевым словам, пункт правил моделью на scikit-learn, черновик по шаблонам на 6 языках. Решения о платежах, банах и взломе всегда уходят человеку.

## Технологии:
Python, FastAPI, Pydantic, scikit-learn, lingua, Streamlit

## Использование ИИ:
Основа кода и шаблоны ответов созданы с помощью Claude, далее дорабатывались и проверялись мной. Шаблоны на казахском и узбекском требуют проверки носителя.

## Метрики на валидации:
Язык 85.7%, пункт правил 86.2% (125 из 145, только среди тикетов, где он указан), нужен человек 78.5%, 5.3 мс на тикет, стоимость API: 0.

## Ограничения:
Модель знает не все пункты правил, остальные уходят человеку. Дубли и спам определяются упрощённо. Факты из текста игрока не проверяются.
